# Help

The keyboard reference, About with the version and the bug report, and Support.

[← All documentation pages](README.md)

![Help page](../screenshots/help.png)

- **Keyboard:** the complete keyboard reference (the menu bar's Help → Keyboard shortcuts opens it).
- **About:** the version (with the number of commits since the last release and whether the source was modified), links to the project and its releases, and **Report a problem**: it opens a new issue on GitHub in the browser with the version, the system (the computer's operating system and its version) and where the UI was opened from already filled in, under the headings What happened, What you expected and Steps. You see and edit everything before you send it; PitchControl itself sends nothing. Please attach the newest log file: File → Open logs folder, the newest file is the current run. On a phone or tablet on the network it is a plain link that opens on that device. Feature ideas go to [Discussions → Ideas](https://github.com/hlavamir/PitchControl/discussions/categories/ideas), where they can be voted on. **Join the Discord** next to it opens the [PitchControl Discord](https://discord.gg/4nbBaQDKz4) for questions and chat. **Check for updates** next to Releases asks GitHub for the newest release, only when you press it: it tells you whether yours is the latest, or shows the new version with its release notes and a **Download** button that opens the zip for your system in the browser (the app downloads and installs nothing itself; without internet it says it couldn't reach GitHub).
- **Support:** PitchControl is free; the Ko-fi link takes donations.
